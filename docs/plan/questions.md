# 待用户决定的问题

开发者遇到需要用户拍板的事情时写在这里，**写完按"默认方案"继续工作，不要停下来等**。用户回答后，开发者按回答调整。

格式：

```
## Q<编号> · 问题标题（状态：待回答 / 已回答）
- 背景：
- 选项：A … / B …
- 默认方案（先按这个做）：
- 用户回答：
```
