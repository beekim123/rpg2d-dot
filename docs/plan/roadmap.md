# 里程碑

按顺序推进，**不设日期**。每个里程碑结束时，游戏都应该是一个"能玩、能从头玩到当前进度"的版本。

完成一个里程碑的通用条件：
- 验收清单全部打勾（写在 `progress.md` 里）
- 所有测试、内容检查、美术校验通过
- 自动通关测试覆盖到当前章节并通过
- 一组当前版本的截图（地图、对话、战斗、菜单各至少一张），路径记在 `progress.md`
- 打 git 标签（例如 `m1`）

---

## M0 · 地基

目标：搭好所有"管道"，后面只需要往里加内容。

- 项目脚手架（技术栈见 [tech/architecture.md](../tech/architecture.md)）、README、.gitignore、CI
- 美术管线 v0：调色板、PNG 编码、字符画精灵、程序化素材、`build` / `verify` / `sheet`
- 工作台 v0：素材库 + 动画预览
- 字体接入（Fusion Pixel，含许可证）
- 游戏外壳：主循环、480×270 整数放大、输入、场景栈、文字渲染
- 文本地图读取和绘制、地形自动拼接、按格移动、镜头、碰撞
- 对话框（头像、逐字显示）、简单剧情脚本解释器
- 存档 / 读档
- 调试网址参数和调试菜单
- 合成引擎 v0：能合成并播放几个音效和一段测试旋律

**验收**：打开网页 → 标题 → 在一张测试地图上走动、和 NPC 对话、存档读档；工作台能看到素材和动画；测试全过。

## M1 · 竖切片：序章完整可玩

目标：用序章证明这个游戏好玩、好看、好听。**这是最重要的里程碑，质量标准就是整个游戏的质量标准。**

- 灯谷镇全部地图（白天 / 黄昏 / 祭典夜）、室内
- 芬恩、艾拉、霍伯、布丽欧、镇民、影匠、赝星兵的全部精灵和头像
- 晨星、月桂、灰手三颗伴星的精灵
- 序章全部剧情（见 [02-story.md](../design/02-story.md) 序章 1–11）
- 战斗系统核心：战场、本体与伴星、星绳、时间轴、意图、普攻与技能、击退、胜负
- 艾拉教学战、影匠剧情战
- 伴星名片演出、觉醒演出
- 灯柱（存档 + 回复）、旅灯
- 曲目：标题、灯谷镇、星落祭之夜、袭击、觉醒、普通战斗；全部所需音效
- 标题画面、主菜单（队伍 / 伴星 / 道具 / 存档 / 设置）

**验收**：一个新玩家从标题开始，不看任何说明，30–45 分钟玩完序章，看到标题字幕，并且想继续玩。
