## 阶段与存档约定

阶段规则独立于场景树，输入是已校验探索快照与真实事件，输出是一次性事务和表现请求。旧NPC命令数组继续走StoryRules；新主线分段由独立播放器使用同一原生DialogueBox，不把丰富演出塞进旧脚本格式。

v3新增剧情信息仅用布尔flags和既有inventory/lamps。演出中的临时位置、帧、游标不写存档；在可控边界提交阶段，重载会从最近安全边界重建场景。跳过显示摘要并提交同一非战斗结果，不能伪造战斗胜利、三次敌行动、有效命中或谜题完成。未开启主线的旧v3探索存档仍可继续，不强行清空改成新游戏。

旅灯一直使用同一`hob_travel_lamp`库存键：晨间借出、祭典前归还、余波正式托付；吊坠`item.star_pendant`只能领取一次。探索库存含关键道具，进入战斗时只抽取正式战斗物品并检查每种上限，真实胜利才合并剩余补给和推进阶段。失败重试恢复本场战前库存；预览战斗保持原有“原样返回探索”语义。

地图锚点须有统一解析和安全落点检查，不将NPC占位格当作玩家落点。现有战场是`lv.town`的`arenas.square`。设置`p.s09_done`必须同时保留`p.attack_started`，否则日常/黎明NPC会重叠；家中余波结束才设置`p.aftermath_heard`，然后霍伯转到灯铺。状态变化如果压住玩家或堵门，拒绝事务并选择明确的安全锚点，不绕过存档几何校验。
