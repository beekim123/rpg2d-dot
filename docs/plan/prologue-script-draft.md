# 序章《灯谷镇的黄昏》脚本草稿

> 状态：2026-10-25 剧情准备草稿，供当前开发代理在战斗交付后接入。不是正式内容，不表示脚本已运行、时长已实测、美术/声音已完成或用户体验已验收。本文件只提出台词、交互与接入约定；不修改既有【定】、游戏数据或进度。
>
> 本次范围：既定 11 节拍、10 名镇民、一个可选谜题、接入清单。台词、人物补充、坐标布局与演出细节均为【建议 / 留白】。实施人：主代理；当前无需用户操作。

## 1 · 约束与脚本记法

依据：`../design/01-world.md` 七法则、`../design/02-story.md` 序章与伏笔表、`../design/03-characters.md` 角色、`../design/07-exploration.md`、`../design/08-content-plan.md`、`m1-implementation.md`；同时参考 `../design/04-astrals.md`、`../tech/architecture.md` 与 `../audio/audio-direction.md`。已查阅 `questions.md`，按 Q5 默认解释：封存不改变伴星的唯一灵魂归属。

- **11 节拍顺序固定。** 可选 NPC 与面团谜题只插在日常窗口；不会替代或阻止主线。
- **一人一星。** 霍伯是无星者；新增镇民中只有缇娅拥有新增伴星。艾拉只有月桂，布丽欧只有发酵。赝星兵画清士兵本体与灰色赝星的区别。序章不解释影匠身世、灰手来源或双生之星。
- **唯星可见。** 玩家始终看见伴星；觉醒前的芬恩、霍伯及无星镇民只看到叶子、纸、面团等实体结果。芬恩不注视伴星、不躲其手、不指认其轮廓；知道名字不等于看得见。孩子们默认全是无星者。
- **旅灯交接不冲突。** 早晨由霍伯把自己的旅灯借给学徒点灯；祭典前归还。余波时才正式托付。两次均为同一物件 `hob_travel_lamp`，背包同一唯一道具，不能复制。未觉醒时不能用晨星点灯。
- **每段主场景最多 12 句。** 下列每个编号是一条 `say`，`／` 表示建议人工换行，不表示说两遍；最长按中文 18 字/行预排，最终仍须在正式字体与姓名框中检查。操作提示、战斗状态、任务名使用独立 UI 文本，不混入人物台词。
- **可操作优先。** 没有倒计时对话、反应失败或必须精确按拍的剧情操作。连续演出之间交还方向键/调查键；跳过只跳演出，不能跳两场战斗或自动完成谜题。
- **音乐只用仓库代码合成。** 本草稿仅使用六首 M1 既定曲目 ID：`title / lantern_vale / festival / crisis / awakening / battle`。余波使用 `lantern_vale` 的稀疏编配片段，不临时扩成第七首曲目。所有音效也由现有合成管线制作。

### 稳定 ID 与状态

主场景 ID 固定为 `prologue.01.legend` 至 `prologue.11.departure`。正文台词 ID 用 `<scene_id>.01`、`.02` 顺序编号；新增插句用 `.02a`，不把后续 ID 全部重排。NPC 对话另用 `lv.npc.<id>.<phase>.01`；支线用 `lv.dough.<stage>.01`。剧情文本放多语言表，脚本只引用 ID。

`p.*` 为本草稿建议的新布尔剧情 flag。所有 flag 默认 false；结束 flag 只在相应结果真正提交后设置。`p.sNN_done` 为主线单向进度；不靠已经说过几句话判断完成。战斗计数留在正式战斗状态，不能用布尔 flag 冒充三次敌方行动。地图位置使用具名 anchor；正式地图确定后再转坐标。

| 场景 | 位置 / 玩家目标 | 触发条件 | 成功结束 flag 与下一步 |
|---|---|---|---|
| `prologue.01.legend` | 传说静帧 → 芬恩家 | 新游戏且非 `p.s01_done` | `p.s01_done`；床边接霍伯叫醒段 |
| `prologue.02.lamps` | 芬恩家 → 灯铺门前 → 三盏镇灯 | `p.s01_done`，床边开始叫醒段 | `p.s02_done`；认过布丽欧并点完三灯后去溪桥 |
| `prologue.03.daily` | 面包房门前 / 镇广场 | `p.s02_started` 且 `lamp_bakery` 已亮，调查面包摊 | `p.s03_done`；可先做日常再补剩余灯 |
| `prologue.04.ella_returns` | 溪桥树下 | `p.s02_done && p.s03_done`，进入桥头 anchor | `p.s04_done`；回广场向霍伯交还旅灯 |
| `prologue.05.festival` | 广场、放灯台 | `p.s04_done && p.borrowed_lamp_returned`，主动选“开始祭典” | `p.s05_done`；吊坠入包，放灯后袭击 |
| `prologue.06.ella_battle` | 广场空地 | `p.s05_done`，放灯动作结束 | `p.s06_done`；仅 `prologue_ella` 胜利可进入摘星 |
| `prologue.07.starpluck` | 广场空地 / 艾拉倒下处 | `p.s06_done`，回到探索表现层 | `p.s07_done`、`p.ella_starplucked`；到艾拉身边 |
| `prologue.08.awakening` | 同一空地 | `p.s07_done`，调查艾拉身旁的断灯 | `p.s08_done`、`p.awakened`；晨星 I 显现 |

| `prologue.10.aftermath` | 芬恩家 → 灯铺 | `p.s09_done` | `p.s10_done`、`p.travel_lamp_owned`；黎明去南门 |
| `prologue.11.departure` | 镇南门 → 镇外麦田路 | `p.s10_done`，主动调查南门路牌 | `p.s11_done`、`p.departed`；序章结束、第一章入口 |

日常窗口的 `s02` 与 `s03` 可交错，但 `s04` 等待两者；“顺序固定”指叙事首次介绍顺序，首次面包摊介绍在第一盏灯后解锁。日常空闲时间可以回家、查路牌、存档或做支线，不会自动入夜。

## 2 · 主线逐场草案

### `prologue.01.legend` · 落在掌心的光

**位置**：静帧层 `prologue.legend`，结束进入 `lv.finn_house@bedside`。首屏确认后解锁声音；黑屏短旁白配 4 张代码绘制静帧：仰望星空的人、天心碎裂、碎光落进田野与河流、掌心未燃的灯。传说不是客观真相的旁白录像，不出现“天心主动牺牲”的答案。

**动作与声音**：`title` 主题稀疏片段；每张画面确认翻页，随时可开“跳过传说”摘要。最后显示“星落历 312 年 · 星落祭”，不在这里显示游戏全名；正式《伴星 ASTRA》留给出发。

1. 旁白：从前，夜空里最亮的星，／人们叫它“天心”。
2. 旁白：三百一十二年前，／一个夜晚，它碎了。
3. 旁白：碎光落进风、河流和土地，／也落进了人们心里。
4. 旁白：有人在最不肯退让的一刻，／看见了自己的伴星。
5. 旁白：也有人一直没有看见。
6. 旁白：可每到这一天，／大家还是会把灯点起来。

**交还操作**：静帧由玩家确认推进，淡入时芬恩仍在床上；门外拍门声引出下一节拍。霍伯叫醒的两句后立刻让玩家自行下床、调查、出门，不把早晨接成整段自动过场。

**提交**：静帧结束设置 `p.s01_done`；跳过效果相同。首个安全点是床边，无星、无晨星、未持旅灯。

### `prologue.02.lamps` · 今天的第一盏

**位置**：`lv.finn_house@door` → `lv.town@lamp_shop_front` → `lamp_bakery / lamp_bridge / lamp_square`。这三灯在一条环形路上；桥头视野能看见下一盏。不是收集十二盏灯，不加材料或油量跑腿。

**触发与控制**：霍伯隔门用第 1 句叫醒芬恩，芬恩坐起回第 2 句，随后设 `p.woken` 并交还操作。玩家拿起门边点灯杆、出门，主动面对灯铺门前的霍伯时才说第 3–4 句并借灯。与霍伯完成借灯后设 `p.s02_started`；第一灯点亮时解锁 `s03`。床头画像可选调查文字“画里两个人的围巾，系在一起。”，不发奖、不解释吊坠；不是必读目标。

1. 霍伯：芬恩！太阳都到屋檐了，／你的靴子呢？
2. 芬恩：已经穿好了！／……有一只在脚上。
3. 霍伯：灯不会自己亮。
4. 霍伯：拿我的旅灯，先点面包房前那盏。

**操作段 A**：玩家走到面包房灯柱，确认。显示手持旅灯接引火种的小演出；灯罩亮、灯绳轻摇、点灯合成音。立即显示一个可关闭的提示：“灯已点亮：可存档、回复。”玩家可实际打开一次存档菜单，但不强制写槽。

5. 芬恩：亮了。它比我醒得快。
6. 霍伯：再点溪桥和广场那两盏。／路上的人，也抬头看看。

**操作段 B**：前往面包摊触发 `s03`；然后自主完成另外两灯。三灯只点一次；灯柱 id 落入正式 `lamps` 集合，不同时维护会分歧的副本计数。全部已亮才设 `p.s02_done`。不用硬等天黑：白日点的是为祭典试灯，日落后继续燃着。

7. 芬恩（三灯完成）：三盏都稳了。／去桥头看看巡逻队吧。

**任务文字**：未完成时“点亮面包房、溪桥、广场的灯柱（N/3）”；完成但未认识布丽欧时“去面包房前打个招呼”；其余为“去溪桥接艾拉”。`lantern_vale` 正常编配全程续播，不为每盏灯重起音乐。

### `prologue.03.daily` · 面包比门大

**位置**：`lv.town@bakery_counter`，第一灯旁。布丽欧捧着面团，玩家看见「发酵 RISE」在盆沿鼓起腮帮；芬恩视线始终跟着面团。发酵只令面团膨胀，不擅自长手替主人揉面或搬重物。

1. 布丽欧：今天的甜饼，一人一颗星！
2. 芬恩：你这盆……快长出一座山了。
3. 布丽欧：发酵，够了。／客人没那么大的嘴。
4. 芬恩：我看不见它，／可我看得见门要遭殃了。
5. 布丽欧：先尝一块。／烤坏的归我，烤好的归大家。
6. 芬恩：那你今天可不能饿着。

**操作与提交**：确认“尝一块”获得本日一次祭典甜饼（恢复数值由正式道具表定；不得重复领取）。之后 `p.s03_done=true`，交还控制。接不接面团支线都可离开。旁边孩子正试着把纸星放到镇长帽顶；主动调查纸星可将它递回孩子，触发 2 句独立 NPC 对话，不产生主线必须 flag。

**支线入口**：面包房门口膨胀的面团顶开门，布丽欧先收回发酵，留下一屋子已经变大的面团。冒出可关闭的“面团的反抗”图标；任务牌明确“可选，可随时离开”。普通日常音乐继续，面团弹跳音很轻。

### `prologue.04.ella_returns` · 看不见的叶冠

**位置**：`lv.town@creek_bridge`，两名孩子、艾拉和芬恩。桥面永远保留一格通路；表演发生在岸边树下，不堵存档灯。

**动作**：艾拉沿桥走来；镜头只移动一小段，镜头落稳即交给玩家靠近。艾拉借月桂把几片真实落叶托成叶冠。玩家看见月桂；孩子与芬恩看到叶冠悬浮，不是孩子突然看见了伴星。每次叶冠飘动，芬恩追看的是落叶。

1. 艾拉：都站稳。／月桂，给他们留片最好看的叶子。
2. 米栗：叶子站起来了！／能给我的饼也戴一顶吗？
3. 芬恩：我知道她在这儿。／只是……不知道在哪边。
4. 艾拉：月桂在我左边。／你不用假装看得见。
5. 芬恩：我什么时候才能觉醒啊。
6. 艾拉：不知道。／可今天的灯，是你点的。
7. 芬恩：那是工作，又不是本事。
8. 艾拉：那我回家的路，／就交给这份工作了。

**玩家操作**：对话结束可调查落下的实体叶片，芬恩用手接住；没有“触摸月桂”交互。主线结束设 `p.s04_done`。任务变为“去广场找霍伯，交还旅灯，再开始祭典”。艾拉从这里到广场的跟随表现是剧情随行；不开放菜单里的正式队员或战斗能力。

**轻松收束**：两只小虫从叶冠掉下，艾拉明显后退半步，芬恩替她拨走；不加新台词，不拖成喜剧长段。回忆“可靠的姐姐也会怕虫”供将来营火回收。

### `prologue.05.festival` · 两个人的一颗星

**位置**：`lv.town@festival_square` → `release_platform`。把旅灯归还霍伯后设 `p.borrowed_lamp_returned`，唯一道具退出借用背包。玩家确认“开始祭典”前，提示“日常支线可留待以后；现在开始祭典？”并可取消，不能借此锁支线成败。

**入夜**：玩家点头后一次淡出、切夜间调色板、NPC 换站位。三盏已经点亮的灯保留；`festival` 从稀疏铃声到完整编配。玩家先操作芬恩给纸灯选一个折口形状、把实体甜饼掰成两半；选择只改小动作，不埋数值优劣。无需重复搜集材料。

1. 镇长托兰：我只说三句。／第一句，今晚真是个好——
2. 布丽欧：镇长，甜饼要凉了。
3. 镇长托兰：第二句，开吃！／第三句也一样！
4. 艾拉：芬恩，把手给我。
5. 芬恩：先说好，／我没偷吃你那半块。
6. 艾拉：这是爸爸妈妈留下的。／现在，你来保管。
7. 芬恩：里面这点亮光，是什么？
8. 艾拉：一粒星屑。／他们一直把它留在这里。
9. 芬恩：那今晚的星星，／我替他们多看一眼。
10. 艾拉：先把今晚的灯，放稳。

**伏笔与动作**：星形吊坠静帧局部明确看见内部一粒星屑；不发出晨星轮廓、不解说天心核心、不触发进阶。`item.star_pendant` 唯一入包并设 `p.pendant_received`。芬恩把它放在衣领内，玩家移动两步到放灯台，确认放灯后 `p.s05_done=true`。此时才过渡袭击；不会在玩家吃饼或看菜单时突袭。

### `prologue.06.ella_battle` · 留出回家的路

**位置**：`lv.town@arena_square`，同一片已走过的广场。面包摊、灯柱、出口仍可辨认；祭典群众沿两条既定路线撤出战场范围，避免兵与村民互相穿模。

**开场**：远处纸灯突然横移；月牙黑面具士兵出现。`festival` 截断后留短暂静默，再入 `crisis`。士兵的灰色无面赝星由玩家看见；未觉醒芬恩看到的是摊架被撞翻与士兵动作。影匠在路口现身，不在此处露出灰手名片。

1. 艾拉：孩子们，从灯铺那边走！
2. 芬恩：我帮你！
3. 艾拉：好。把包里的面包拿稳，／听见我叫你再过来。
4. 芬恩：你往前走。／后面我看着。

**玩家操作与战斗触发**：控制焦点切换到艾拉；先给可关闭提示“现在操作艾拉与月桂”。由地图 arena 触发已有配置 `prologue_ella`。首个可控回合显示艾拉 / 月桂名片一次，随后立即让玩家选移动或技能；不用先播一大段规则讲解。

- 目标：击退赝星兵，实际由敌方本体倒下/战斗胜利判定完成；不要求一定使用指定技能，不把“击退”误绑定为测试技能 `rush`。
- 学习顺序：选艾拉/月桂 → 看清攻击范围 → 执行攻击 → 需要时治疗或护盾。已经掌握的人可自由行动；没有强制挨打以解锁治疗的步骤。
- 芬恩是无星辅助位：不能召晨星、发星技能或攻击赝星。道具辅助必须走交付后的正式道具指令；呐喊只播放短句，没有隐藏的攻击/伤害增益。**当前战斗数据只有艾拉一个可控角色，辅助接入属于待主代理补齐项，不假称已有。** 不在剧情脚本里私改 HP、心力或敌意图。
- 命中月桂后体现艾拉同伤共痛；她可短促弯身而不加长台词。按需只播一次第 5 句，不重复阻断回合。

5. 艾拉（首次月桂受伤）：别让月桂离我太远。／我们是一起受伤的。
6. 芬恩（使用道具后）：接住！别逞强！
7. 艾拉（胜利）：都出去了吗？／芬恩，跟在我身后。

**音乐与失败**：战斗开始换 `battle`，胜利不播欢庆长乐句；回到 `crisis` 的低音。失败显示“重试这场战斗 / 返回战前灯柱”；加载战前快照，恢复补给与辅助次数，不设 `p.s06_done`，不进摘星。只有真实胜利后设 `p.s06_done`。

### `prologue.07.starpluck` · 灯下突然空了

**位置**：同一广场 `ella_fall`，用关灯与声音变化制造失去，不靠血腥或持续闪白。

**动作**：胜利后先让玩家操作芬恩走到艾拉背后。影匠拦住离场方向、灰手显现；镜头拉到能看见艾拉本体、月桂与影匠的范围。灰手拽动月桂，星绳被拉直后断为粒子，月桂被封进实体星匣；艾拉随之失去意识。不是月桂投靠影匠，不让失去意识的艾拉继续操纵月桂。

1. 艾拉：别过来。／这个人和刚才的不一样。
2. 芬恩：姐，你的手在抖。
3. 艾拉：去灯铺。现在。

## 5 · 节奏预算与可玩内容

下表是**首次游玩目标分配，未经试玩**。玩家熟悉操作或跳过对话后明显更快是正常现象；禁止用强制慢走、重复对话、无意义战斗或等待时间填表。

| 段落 | 目标分钟 | 支撑时长的玩家行为 |
|---|---:|---|
| 传说、起床与第一灯 | 3–4 | 调查、移动、第一次面对交互、可选打开存档 |
| 日常、余下两灯、姐姐归来 | 6–8 | 顺路探索，纸灯/叶冠实体互动，少量自选镇民闲聊 |
| 祭典与吊坠 | 3–4 | 主动开始祭典、折口选择、分甜饼、放灯 |
| 艾拉教学战 | 5–7 | 读一次范围、控制本体与月桂、做攻守选择 |
| 摘星与觉醒 | 3–4 | 走到姐姐身边、扶灯，短演出与名片 |
| 影匠战 | 5–7 | 保护本体、判断意图、完成两个公开目标 |
| 余波与黎明出发 | 3–4 | 看望艾拉、接灯、主动走出镇子、点路灯 |
| 主线目标合计 | 28–38 | 大致落在 30–45 分钟目标附近，需实测调整 |
| 面团支线 / 额外闲聊 | 自选 3–6 | 单房间推板与少量人物趣味，不是主线时间保证 |

若实测主线明显少于 30 分钟，先查战斗是否被自动化代做、城镇是否只有直线、互动是否只是按下一句；补充有选择的空间和局势，不能要求玩家做完支线凑时长。若超过 45 分钟，优先减战斗重复回合与地图绕路，保留失去、觉醒与旅灯交接的情感停顿。

## 6 · 主代理接入清单与实施顺序

### 已有能力与缺口

2026-10-25 读取时，`src/systems/story.ts` 仅有 `say / set / if / move / end`，`move` 只支持 NPC 坐标变更；`src/systems/world.ts` 的 `GameState` 有布尔 flags、灯柱集合、背包及地图位置，但没有完整队伍、地图阶段或可持久化剧情续播结构。内容已有 `prologue_ella`、`prologue_shade` 两场候选配置。**下面名称是待实施语义，不是已存在指令，不可直接把伪指令塞进 v0 JSON。** 战斗交付后的实际接口为准。

| 需要的脚本语义 | 最小行为与引用检查 | 使用处 |
|---|---|---|
| `say / set / if / end` | 沿用现有；文本 id、speaker、portrait 均存在；结束 flag 幂等 | 全部场景 |
| `choice` | 只暂停当前场景；可取消；返回合法分支；默认不替玩家作答 | 开始祭典、出发、支线接取 |
| `objective` | 稳定任务 ID、明确地图目标；读档可由旗标重建 | 点三灯、找艾拉、赤砂城方向 |
| `interact_object / trigger_once` | 面向物件确认、区域进入；结束前不重复入队列，不能重入复制奖励 | 静帧、吊坠、灯、床、放灯台 |
| `map_transfer / phase` | 进入有效地图及 anchor，保持出口对应；昼/暮/夜/余波布置共用逻辑灯 id | 五张地图、时间推进 |
| `actor_stage / face / route` | 显示/隐藏/朝向/有限步行；先校验占位，不瞬移穿过玩家；NPC 失败移动有安全回退 | 归来、疏散、摘星、撤退 |
| `control / party_guest` | 焦点芬恩↔艾拉；剧情跟随与战斗角色分清；不能因读档留错控制人 | `s04`、`s06`、`s08` |
| `music / sound / camera / fx / still` | 每种都有可跳过和减弱版本；逻辑不依赖音频结束/帧率；资源引用必须可校验 | 静帧、祭典、觉醒 |
| `astral_card` | 从角色正式数据读伴星名/六维；已看/跳过状态不跳战斗 | 艾拉、晨星、影匠可用简短敌名片 |
| `inventory_transfer / give_once` | 旅灯唯一所有者；吊坠一次；补给与支线领奖幂等 | 借灯、吊坠、正式托灯 |
| `battle` | 地图 arena + 配置 id + 战前快照；胜/负分支；结果提交一次；等表现结算再回地图 | 两场战斗 |
| `support_item / battle_bark` | 芬恩无星辅助经正式战斗接口，道具效果公开；呐喊纯表现 | 艾拉战（尚缺接入） |
| `checkpoint / resume / skip_summary` | 在可控边界保存；保存演出中则记录场景与恢复点，不能重领物品；跳过给概要及等价非战斗状态 | 所有强制演出 |
| `puzzle_reset / solve_once` | 本局摆位与永久奖励状态隔离；离开可重置，无主线耦合 | 面团支线 |

名片不需要把“灰手的外来归属、星傀”等秘密放进玩家图鉴；序章只显示可见的“影匠 / 灰手 ASH HAND”。普通镇民的伴星不要求完整战斗面板，不能为生活演出扩出一套无用战斗数值。

### 连续实施顺序

1. **当前战斗交付完成后，由主代理核对接口**：两战胜败/重试/目标展示已通过，确定故事调用方式；单独补芬恩道具辅助缺口，不能为接剧情倒改已验收的意图规则。

3. **一次性结果与恢复**：先验证借灯→归还→托付、吊坠、两战回传、`p.awakened` 与角色切换；补战前/演出安全点恢复和旧 M0 存档迁移。自动路线跑通后再扩演出，避免后期修旗标。
4. **镇民与支线**：放置 10 人，处理所有无星视角；接缇娅生活演出；面团基础版先可重置/可退出/领奖一次，再决定是否保留变化版。支线尚未完成时主线自动路线仍必须通过。
5. **正式表现与声音**：代码绘制缺失人物/伴星/建筑/静帧；build→verify→sheet→看图；配六曲与短音效；正式字体逐句检查换行，实景检查昼暮夜与原地战斗，音频数值检查后另做听审。
6. **完整验收**：11 节拍从标题连跑，两战各失败一次再胜利；分段存读档和跳过概要；完整手玩记录真实时长及误解。主代理统一更新 `backlog.md / progress.md / ../v2/status.md`，只在满足 M1 门槛后标记正式验收。

## 7 · 接入时必须查的风险

| 风险 | 应验证的具体结果 |
|---|---|
| 前期点灯提前拿到“正式托付”的旅灯 | 早晨是借用，祭典前归还；余波正式取得；全程同一唯一物件，没有第二盏感应旅灯 |
| 芬恩/孩子/Hob 在觉醒前看到了星 | 对话和视线只回应物理结果；只有玩家的客观画面展示伴星；觉醒后才新增“看见”的反应 |
| 失败也推进摘星或余波 | `s06 / s09` 仅由对应真实胜利写入；失败优先和重试补给恢复均通过 |
| 三回合被演出冒充或误写为三次受伤 | UI 与逻辑均读取敌方实际行动计数；可防御/躲避；命中要真实结算，不回放记第二次 |
| 摘星变成伴星转让 / 霍伯暗藏能力 | 月桂的归属始终是艾拉；霍伯只观察实体旅灯反应；不写新携星者身份 |
| 面具裂角提前泄露身份 | 不露面、不落可辨识照片、不出现“塞拉斯 / 哥哥 / 维斯珀 / 双生”文本 |
| 时间切换与跳过复制道具、漏旗标 | 每个阶段有单一状态提交点；跳过只应用等价非战斗结果；战斗必须打，支线解答不自动发生 |
| 镇民退场把必经路堵死 | 每个地图阶段都检查可达性；重试回到同一有效布局，非战斗 NPC 不占 arena |
| 面团变化布局口头上可解但实际不可解 | 作为候选重新跑推板/可达性校验；不通过则保留基础版；退出和复位始终可用 |
| 30–45 分钟成为灌水指标 | 记录主线与自选支线分开时长；保留有效操作，不强制听 10 人台词或反复取物 |
| 把准备文档当完成标记 | 本文件只能标“草稿已写”；正式脚本、素材、声音、技术审核、用户体验验收逐项另记 |
