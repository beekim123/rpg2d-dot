# 进度日志

开发者每完成一次有意义的提交，就在**最上面**追加一条。用户通过这个文件了解进度。

格式：

```
## YYYY-MM-DD · 简短标题
- 做了什么（对应 backlog 的哪几项）
- 提交：<短哈希>
- 截图 / 对照表：<路径>
- 改了哪些【建议】，为什么（没有就省略）
- 已知问题 / 下一步
```
