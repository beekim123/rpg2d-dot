# M1 · 序章竖切片实施计划

**目标**：让玩家在灯谷镇经历日常、祭典、袭击、艾拉失星、芬恩觉醒和黎明出发；完整序章的情绪与战斗体验达到后续章节的质量基准。
**依据**：`design/02-story.md` 序章11节拍、`design/05-combat.md`、角色/伴星/美术/音乐规范。M0原型只作基础，不能据此宣布序章完成。
**架构**：保留纯逻辑状态与Canvas表现分离。战斗状态独立于探索状态，产出事件由地图原地战斗层播放；剧情在战斗结束后应用胜负结果。所有数据、台词、图片与音乐来自仓库。

## A · 可单独验证的战斗核心

- [ ] A1 数值与规则基础：`src/battle/model.ts`、`math.ts`、`tests/battle-math.test.ts`。确定性伤害、星距、共享体力、收回保护、倒下熄灭；E–S评级与速度时间轴。用手算边界样例先红后绿。
- [ ] A2 回合状态机：`engine.ts`。输入当前状态/指令，输出新状态/事件；本体移动、伴星移动、撤销移动、一次主行动。移动不得穿墙/穿单位，不得用多次移动绕过移动力；本体移动拖回伴星，空间不足时收回并明确提示。
- [ ] A3 技能与战斗目标：晨星灯拳/灯印/照破、月桂攻击/治疗/保护、收回/显现/待机、击退/碰撞。数据放`content/data/`。序章影匠的胜利要求真实承受三次敌方行动且命中一次，生命归零仍进入重试。
- [ ] A4 时间轴和确定性敌人意图：平手我方优先、再按队伍序；意图在上次行动结束时确定，不因玩家移动暗改。定点与锁定明确区分。
- [ ] A5 逻辑自动路线分别跑艾拉教学战和芬恩影匠战，并覆盖失败后重试。每完成A子项独立检查/提交，不把算式模块视为可玩战斗。

A1具体约定：曼哈顿距离；伤害使用文档公式、结尾Math.round；星绳为0或越界不可攻击；h=ceil(R/2)，R=1不得除零。共享HP适用于close/remote；未来auto/set/swarm不能误走共享伤害。攻击本体倍率1.5，收回本体0.7，伴星1.0，盾先抵扣结算伤害；HP归零同时清空伴星位置。时间刻度用整数，100×速度系数×动作权重后四舍五入，排序保持稳定。

## B · 正式灯谷镇与角色素材

- [ ] 扩充草地、麦田、溪岸、木桥、花草、灌木、风车、灯铺/面包房及祭典灯笼，建筑按部件组织。
- [ ] 芬恩家/灯谷镇/灯铺/面包房/镇外路；昼/暮/夜调色板映射。每图出口一致、必经点可达，灯柱明确。
- [ ] 艾拉/布丽欧/镇长/孩子/路人/影匠/赝星兵，配各自头像；晨星/月桂/灰手/发酵，遵守四芒星核与伴星独立描边。
- [ ] 每批build→verify→sheet→看图→实际地图截图，M0旧素材不自动视为正式验收。

## C · 原地战斗与演出

- [ ] 战场矩形内原地展开、星绳、单位切换/移动范围、预计伤害、时间轴、敌意图、指令菜单；键盘和鼠标可用。
- [ ] 命中停顿、调色板受击闪白、击退；动画速度/闪白/震动可关闭。战斗逻辑与动画等待互不影响。
- [ ] 伴星名片：芬恩/晨星、艾拉/月桂、影匠/灰手；六维星图与名字；觉醒定格、原创拟声。
- [ ] 失败重试与回灯柱，无扣罚，无剧情死局。

## D · 11节拍剧情、声音与主菜单

- [ ] 按既定顺序制作：传说静帧→起床→点灯日常→姐姐归来（芬恩看不见月桂）→祭典吊坠→操作艾拉教学战→摘星→觉醒名片→影匠战→余波旅灯→黎明出发标题。
- [ ] 关键伏笔：霍伯口头禅、吊坠星屑、旅灯感应、影匠“找到了，晨之星”。不提前泄露后章真相。
- [ ] 角色对白短、有区别；镇民至少10名与趣味伴星支线入口。主线目标总能告诉玩家去哪里。
- [ ] 六首正式曲目与所需音效/说话音；纯代码合成，逐首数值检验并尽可能实际完整试听，不以数值冒充听感。
- [ ] 队伍/伴星星图/道具/存档/设置主菜单；存档迁移后仍可恢复旧M0存档。
