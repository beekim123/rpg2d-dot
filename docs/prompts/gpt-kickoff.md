# 给 GPT 的提示词

把下面的提示词直接复制给 GPT（Codex 等编程智能体）。仓库根目录的 `AGENTS.md` 会被大多数编程智能体自动读取，提示词里也会让它主动去读。

使用说明：
- **第一次开工**用"启动提示词"。
- 会话结束或中断后，用"续跑提示词"接着做。
- 每完成一个里程碑，或者感觉质量在下滑时，用"自查提示词"。
- 你试玩后有意见，用"反馈提示词"。
- 如果 GPT 不是在你这台电脑上运行（比如云端），它看不到 `.local/reference/style-ref-01.webp`，请在第一条消息里把参考图作为附件发给它。

---

## 1 启动提示词

```
你是这个仓库唯一的游戏开发者，一个人负责程序、美术、作曲、编剧和测试。仓库是 https://github.com/beekim123/rpg2d-dot ，当前工作目录就是它。

我们要做一款 2D 俯视角像素风回合制 RPG《伴星 ASTRA》（暂定名）：在一个人人都可能觉醒"伴星"（灵魂化成的战斗化身）的奇幻世界里，主角带着伴星旅行、战斗、修行和成长，走完一段完整的故事。完整的设计文档已经写好放在 docs/，工作规则在 AGENTS.md。

开始之前：
1. 完整阅读 AGENTS.md 和 docs/README.md，再按 docs/README.md 的顺序读完 docs 里的所有设计文档。文档很长，请完整读完再动手，它是你接下来很长一段时间的工作依据。
2. 如果本机存在 .local/reference/style-ref-01.webp，打开看看：这是美术风格参考图（第三方截图，只学风格，不复刻、不提交）。风格要点在 docs/art/art-direction.md 第 1 节。

你的任务：
- 从 docs/plan/roadmap.md 的 M0 开始，一个里程碑接一个里程碑地做下去：M0 地基 → M1 序章竖切片 → M2…M7 各章 → M8 完整游戏 → M9 打磨。
- 按 AGENTS.md 的"工作循环"持续工作：选任务 → 做 → 验证（跑测试，自己看截图和美术对照表）→ 记录 → 提交 → 立刻做下一个。
- 不要停下来问我。需要我决定的事写进 docs/plan/questions.md，然后按默认方案继续。
- 你有很大的自由度。技术栈、架构、美术细节、音乐、对白、支线、数值都可以按你的判断来做；文档里标【建议】和【留白】的地方尤其欢迎你发挥，改了就更新文档并说明理由。标【定】的不能改。

硬性要求（详见 AGENTS.md 的红线）：
- 不调用任何图片 / 音乐 / 语音生成模型。所有图片都用代码画出来，导出成 PNG 存进仓库；所有音乐和音效都用仓库里的代码合成。
- 不使用外部美术和声音素材（OFL 字体除外），不复制任何现成作品的角色、名字、台词、旋律。
- 小步提交；提交前测试通过；每次提交后在 docs/plan/progress.md 最上面追加一条记录。

质量期望：
- 我要的是一个完整的游戏：完整的故事、好玩的战斗、好看的像素美术、好听的音乐和音效，而不是技术演示。
- M1（序章）是整个游戏的质量标杆：新玩家玩完序章就想继续玩。宁可在 M1 多花时间打磨，也不要带着粗糙的东西往后赶。
- 美术要像参考图那样：温暖、饱和、Q 版、清楚的深色描边、俯视 3/4 视角。每做完一批美术都要自己看图检查。

现在开始：先读文档，然后在 docs/plan/progress.md 写一条"开工"记录（你对这个项目的理解、你选的技术栈和理由、M0 的计划），提交，然后开始 M0 的第一个任务，并一直做下去。
```

## 2 续跑提示词

```
继续开发《伴星 ASTRA》。先读 AGENTS.md，再读 docs/plan/progress.md 最上面几条和 docs/plan/questions.md（看我有没有新的回答），然后从 docs/plan/backlog.md 接着做。按 AGENTS.md 的工作循环一直做下去，不要停下来问我。
```

---

## 3 自查提示词

```
先暂停新功能，用挑剔的玩家和美术总监的眼光做一次严格自查：
1. 运行全部测试、内容检查、美术校验和自动通关测试。
2. 把目前能玩的部分从头到尾过一遍：用调试网址逐个场景截图，认真看每一张截图。
3. 列出问题清单：哪里不好玩、哪里看不懂、哪里不好看、哪里没有声音、哪里有 bug、哪里文字溢出、哪里和设计文档不一致。按严重程度排序，写进 docs/plan/backlog.md 的最前面。
4. 修掉所有严重问题，在 progress.md 记录自查结果，然后继续原来的工作。
```

---

## 4 反馈提示词

```
我试玩了最新版本，意见如下：
- （写你的意见，比如"芬恩的脸太小看不清""战斗节奏太慢""灯谷镇的音乐太吵"）

请把这些意见写进 docs/plan/backlog.md 并标为最高优先级，先改这些，每改完一条在 progress.md 里说明改了什么（美术改动附上新对照表路径）。改完后继续原来的工作。
```

---

## 5 美术返工提示词

```
我对（某个角色 / 场景 / 界面）的美术不满意：（具体哪里不好，想要什么感觉）。
请重新设计并重画，重新构建，自己对照 docs/art/art-direction.md 的自查清单和参考图检查。把新旧对照表放在一起给我看（路径写在 progress.md），然后继续原来的工作。
```
