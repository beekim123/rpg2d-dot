# 00 · 愿景

## 1 一句话

**《伴星 ASTRA》**（暂定名）是一款 2D 俯视角像素风回合制 RPG。三百年前天上最亮的星碎裂坠落，从此任何人都可能在某个瞬间觉醒属于自己的"伴星"，那是灵魂化成的战斗化身。玩家扮演一个刚觉醒的点灯人学徒，为了夺回姐姐被偷走的伴星踏上旅途，和伙伴一起锻炼伴星、看破敌人能力的规则，最后揭开"摘星"背后的真相。

> 每个人心里，都有一颗会醒来的星。

## 2 设计支柱【定】

1. **伴星即角色**：战斗、探索和成长都围绕伴星。伴星是本人心性的形状，长相、能力和性格要能互相解释。没有"通用职业"，每颗伴星都独一无二。
2. **能力比数值重要**：靠"看懂规则、用对能力"赢，而不是靠刷等级碾压。每个 Boss 的伴星都有一条或几条隐藏**法则**，看破法则就是破局的钥匙（灵感来自"替身战斗"那种斗智）。
3. **本体是弱点**：伴星受伤，本体同痛；本体倒下，伴星熄灭。站位、射程和保护本体是战斗的核心张力。
4. **看得见的成长**：伴星会通过修行变强（六维星图逐级提升），会在剧情的心境转折点**进阶**，外形和能力都会变化。玩家要能清楚感到"我的伴星长大了"。
5. **完整的旅程**：一个有开头、高潮和结局的完整故事。每一章有一座新城、一个新伙伴、一个能力独特的敌人、一段情感主题。
6. **全部原创、全部用代码做**：美术用代码画出来再存成 PNG，音乐和音效用代码合成。不调用任何图片 / 音频生成模型，不用外部素材（OFL 字体除外）。

## 3 目标体验

| 时刻 | 玩家应该感到 |
|---|---|
| 序章觉醒 | 绝境里第一次喊出伴星的名字，鸡皮疙瘩 |
| 遇到新敌人 | "这家伙的能力到底是什么？"，好奇又紧张 |
| 看破法则 | "原来如此！"，推理成功的快感，角色在战斗中说出推理 |
| 连打终结 | 爽快：画面定格、拟声大字、屏幕震动 |
| 修行 | 短小好玩的小游戏，星图上的字母从 C 跳到 B |
| 星阶进阶 | 剧情高潮里伴星蜕变，新外形、新招式、新战斗曲 |
| 营火夜谈 | 伙伴之间的玩笑和心事，想把每段对话都看完 |
| 结局 | 群星归位，眼眶发热，然后想再玩一遍收集图鉴 |

基调：热血、俏皮、温暖，偶尔沉重。可以学替身战斗那种夸张造型、定格摆拍和拟声大字，但所有名字、设定、台词、造型都必须原创，不能出现任何现成作品的专有名词或明显复刻。全年龄向，不血腥。

## 4 范围【建议】

| 项 | 目标 |
|---|---|
| 通关时长 | 主线 6–10 小时；全收集 12 小时以上 |
| 章节 | 序章 + 7 章 + 终章 |
| 可操作角色 | 7 人（主角 + 6 伙伴，含中途离队 / 回归） |
| 区域 | 7 个主题区域，每区一座城镇 + 1–2 个迷宫 + 野外 |
| 敌人 | 星兽约 20 种、赝星兵约 10 种、独特伴星使 Boss 约 12 个 |
| 支线 | 20 个以上，每区 3–4 个 |
| 曲目 | 16–20 首，同一主题动机的变奏 |
| 语言 | 简体中文为主；文字全部走多语言表，以后可加英文 |
| 平台 | 浏览器（桌面优先，键盘 / 手柄 / 鼠标）。推荐技术方向见 [tech/architecture.md](tech/architecture.md) |

范围可以随开发推进调整，但**先保证从头到尾能通关的完整体验，再加广度**。宁可 5 章做精，也不要 7 章都是半成品。所以开发顺序是先竖切片（序章完整可玩），再按章扩展（见 [plan/roadmap.md](plan/roadmap.md)）。

## 5 不做的事

- 不做随机遇敌：敌人都画在地图上，看得见。
- 不做开放世界、多人联机、抽卡、体力、内购。
- 不做实时动作战斗。时机按键（连打节拍）是可选的加分项，可以关闭。
- 不用 AI 生成的图片、音乐、语音；不用来历不明的素材。
- 不复制任何现成作品的角色、名字、台词、音乐旋律。
