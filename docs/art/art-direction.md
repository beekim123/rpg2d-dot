# 美术方向

美术的**制作方法**见 [art-pipeline.md](art-pipeline.md)。本文规定**画成什么样**。

## 1 参考图分析【定】

参考图在本机 `.local/reference/style-ref-01.webp`（第三方截图，不提交、不复刻，只学风格）。画面内容：黄沙空地上三个小骑士和一个大胡子角色，右下是一座插着红旗的圆形石塔，周围是绿色灌木。从中提炼出的风格要点：

| 要点 | 参考图的做法 | 本作要求 |
|---|---|---|
| 视角 | 俯视 3/4 角度：地面朝上，建筑和人物能看到正面 | 同样。墙体有正面，屋顶有顶面 |
| 比例 | 角色是 Q 版，大约两头身，头盔和帽子很大 | 人物约 1.5 格高（24px），头部占身高 40–45% |
| 描边 | 所有角色和物件外圈一道深色描边，近黑的暖棕色 | 人物、物件、敌人用统一的深色描边；地面纹理不描边 |
| 明暗 | 每种材质 2–3 阶平涂 + 1 点高光，光从左上来 | 同样。不做渐变 |
| 配色 | 暖、饱和、明亮：沙黄地面、鲜绿草丛、米灰石砖、正红旗帜、橙色火焰 | 整体温暖明亮；每个区域有自己的主色调（见 [01-world.md](../design/01-world.md) 第 5 节） |
| 地面 | 沙地是暖黄色，有成簇的浅色斑块和零星的深色小石子 | 地面纹理成簇分布，不要满屏均匀噪点 |
| 草地边缘 | 草地和沙地交界处是一圈圆弧形的深绿草边，像花边一样压在沙地上 | 地形交界用"花边"过渡，代码自动拼接 |
| 植物 | 灌木是一团团圆形叶片，深绿到黄绿 3–4 阶，叶片上有亮点 | 同样 |
| 建筑 | 石砖圆润，砖缝深色；圆塔顶有雉堞；红旗白十字；火把；拱形木门带铁箍 | 建筑用代码按部件拼装，每个区域换材质和部件 |
| 阴影 | 角色脚下一块深一阶的地面色椭圆 | 实色阴影（用地面色的暗一阶），不用半透明 |
| 气质 | 可爱、热闹、像桌游棋子一样清楚 | 同样。任何时候都要一眼看清谁是谁、哪里能走 |

## 2 规格【建议】

| 项 | 规定 |
|---|---|
| 逻辑分辨率 | 480×270，整数倍放大，最近邻，不做亚像素移动和抗锯齿 |
| 格子 | 16×16 |
| 人物（地图和战斗共用） | 帧 16×24，锚点底边中心 (8,24)；大个子角色可用 24×32 |
| 伴星 | 普通 24×32；Boss 伴星 32×32 到 48×48；「蚀」64×64 |
| 敌人 | 小型 16×16 · 中型 24×24 · 大型 32×32 |
| 头像 | 对话头像 48×48；伴星名片立绘 96×96 |
| 图标 | 状态 8×8；道具 / 技能 16×16 |
| 静帧插画 | 480×270 全屏 |
| 动画帧率 | 人物 8 fps；待机和环境 4 fps；特效按需 |

**全游戏一个像素尺度**【定】：所有东西都按同一个像素大小画，不允许放大后的大像素和普通像素混在同一个画面里（伴星名片的放大立绘除外，它是独立的定格画面）。

## 3 调色板【建议】

全游戏用**一套主调色板**（不超过 64 色），每个颜色有名字和角色。源数据里每个颜色用一个字符表示（`.` 表示透明），和 ele-pushbox-arts 的做法一样。

下面是一套**起步调色板**（49 色，按色带从暗到亮）。开发者可以调整，也可以换成公开的像素调色板（例如 Resurrect 64、ENDESGA 64），但要记录来源和许可，并保持"按色带、按用途命名"的组织方式。

| 色带 | 颜色（暗 → 亮） | 用途 |
|---|---|---|
| 描边 | `#1a1220` `#2e1f2b` `#4a3040` | 描边、最暗的阴影 |
| 石 / 暖灰 | `#5c4b4f` `#85706a` `#b09a8a` `#d6c3ab` `#f2e6cf` | 石砖、城墙、布料浅色 |
| 沙 / 土 | `#7a4a2a` `#b06f35` `#d9a04a` `#edc565` `#f7e09a` | 沙地、土路、木头亮面 |
| 草 / 叶 | `#1f3d2b` `#2f6b34` `#4d9a3b` `#86c440` `#c4e070` | 草地、灌木、树 |
| 水 / 天 | `#1c2a5a` `#2a5a9a` `#3f8fd0` `#79c6ef` `#c7ecff` | 水、天空、冰 |
| 红 | `#5a1a2a` `#9a2a2f` `#d6453a` `#f07a5a` | 旗帜、衣服、伤害 |
| 橙 / 金 | `#b04a1a` `#e8792a` `#f7b23a` `#ffe36b` `#fff6c8` | 火焰、灯光、星光、晨星 |
| 肤色 | `#8a4a3a` `#c27a5a` `#eab08a` `#f8d8b8` | 皮肤 |
| 紫 / 夜 | `#2a1840` `#4a2a6a` `#7a4aa0` `#b07ad0` | 夜晚、蚀星会、昏星 |
| 青 / 星辉 | `#1a5a5a` `#2a9a8a` `#5ad6c0` `#b0f4e6` | 伴星光、魔法、雾语林荧光 |
| 金属 / 冷灰 | `#3a4050` `#5a6478` `#8a96aa` `#c4ccd8` `#ffffff` | 铠甲、刀剑、赝星、雪 |

**夜晚与黄昏**用调色板映射表实现：每个颜色映射到它的夜晚版本，整个画面一起换。灯光周围用 4×4 Bayer 抖动把颜色提亮一级。

## 4 伴星的视觉语言【定】

伴星必须一眼就能和人、敌人、物件区分开。

- **描边**：人和物件用调色板最暗的描边色；**伴星用自己本命色的最暗一阶描边**，外加一圈 1px 的"星辉闪边"（2 帧闪烁）。
- **星核**：每颗伴星身上都有一个清楚可见的**四芒星形星核**（胸口、额头、手心等），这是所有伴星共同的标志。
- **悬浮**：伴星离地漂浮（上下 1px 缓慢浮动），脚下没有实心阴影，只有一圈稀疏的网点光环。
- **召唤 / 收回**：四芒星闪光 + 像素粒子聚拢 / 散开。
- **赝星**：同样的结构，但全是冷灰色，没有脸，星核是裂开的。
- **蚀星会和昏星**：紫黑配金边，日环纹样。
- **晨星**：金色和暖白，灯笼和光线纹样。
- **进阶**：每一阶都重画，保留同一个剪影的核心特征，加部件、加光、加尺寸。

## 5 角色

- 每个主要角色要通过**剪影测试**：把精灵填成纯黑，依然能认出是谁（靠帽子、发型、围巾、武器）。
- 关键色写在 [03-characters.md](../design/03-characters.md) 里，必须遵守。
- 4 方向行走：下、上、侧（侧面左右镜像共用）。
- 普通路人用**纸娃娃系统**：头型、发型、发色、衣服、配饰按部件组合，用固定种子生成，可以批量产出不同的村民，但风格统一。
- 头像：比地图精灵细致，表情清楚。同一角色的头像、地图精灵、名片立绘配色必须一致。

## 6 地形与建筑

- 地形按区域主题做成图块集：地面（2–4 种纹理）、过渡花边、悬崖 / 墙体（有正面）、水（2 帧动画的水面高光）、桥、路。
- **自动拼接**：地形边缘由代码根据相邻格计算，地图数据里只写"这是草、那是沙"，不手摆过渡图块。
- **装饰散布**：花、石子、小草按格子坐标的固定哈希来摆，同一张地图每次画出来都一样。
- 建筑用部件拼装：墙段、屋顶、门、窗、招牌、烟囱、旗帜，按区域换材质（灯谷镇木屋、赤砂城砂岩圆顶、白鸥港白墙蓝顶、霜脊黑岩、天枢城白石金顶）。
- 可以交互的东西（宝箱、开关、可推的箱子、灯台）要比装饰更醒目，形状不能和装饰混淆。

## 7 画面层级【定】

画面上的视觉强度从高到低：

1. 玩家角色和伴星
2. 敌人和可交互物件（宝箱、开关、可推物、灯柱）
3. 地形中可走与不可走的区别
4. 地面纹理
5. 背景装饰

下一级不能比上一级更醒目。

## 8 特效

- 用逐帧像素动画，不用旋转缩放模糊。
- 命中火花、拟声大字（"砰""燃！""沙沙"）、状态图标、召唤闪光、看破时的"法则卡翻开"、星爆演出、天气粒子。
- 闪白用调色板替换，透明渐隐用抖动。

## 9 禁止【定】

- 不调用任何图片生成模型；不使用外部图片素材；不描摹参考图或任何现有游戏的精灵。
- 不用渐变、柔边、高斯模糊、半透明叠加光束、AI 风格的光晕。
- 不混用像素尺度；不做任意角度旋转的精灵（特效可以预先画好各个角度的帧）。
- 不用颜色作为唯一的区分信息（比如意图要有图标形状）。

## 10 自查清单

每做完一批美术，开发者渲染一张**对照表**（所有新素材放在一张图上，放大 2–4 倍）和一张**实际游戏画面截图**，逐条检查：

- [ ] 剪影测试通过
- [ ] 只用了调色板里的颜色（工具自动检查）
- [ ] 描边、光照方向一致
- [ ] 放在对应区域的地面上依然清楚（对比度够）
- [ ] 动画循环没有跳帧
- [ ] 和参考图放在一起，气质接近（温暖、饱和、清楚、可爱）
- [ ] 和已有素材放在一起不突兀
