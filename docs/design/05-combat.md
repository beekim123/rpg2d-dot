# 05 · 回合制战斗

## 1 概览

战斗是**小格子战场上的回合制战术**：每个角色是"本体 + 伴星"两个棋子，伴星被星绳拴在本体周围。打赢靠三件事：**站位**（保护本体、控制星距）、**看懂意图**（敌人下一步打哪里是公开的）、**看破法则**（Boss 伴星的隐藏规则）。

设计目标【定】：
- 每一场 Boss 战都像一道有趣的谜题，看破之后有"原来如此"的爽快感。
- 默认**没有随机**：伤害、命中、行动顺序都是确定的。随机只用于画面演出。这样玩家能精确计算，开发者也能写确定性测试。
- 普通战斗要快：熟练的玩家 1–3 分钟打完一场普通战。

## 2 进入战斗

- 敌人都画在地图上，有巡逻路线和视野。碰到就开战，**不切换场景**：战斗就在当前地图上原地展开（镜头不动，以遭遇点为中心框出一块战场，战场外的画面压暗）。
- **先手**：在场外用伴星技能打中敌人（场外按"伴星"键会让伴星向前出一拳），我方先行动，敌人第一回合被眩晕。
- **被偷袭**：从背后被敌人碰到，敌人先行动。
- 每个地图区域预先标好可用的战场矩形（地图数据里的 `arena`），保证战场里的地形有战术意义，而不是随便截一块。
- 战场大小【建议】：普通战 8×6 到 10×7 格，Boss 战最大 12×8 格。

## 3 单位：本体与伴星【定】

每个携星者在战场上是两个棋子：

| | 本体 | 伴星 |
|---|---|---|
| 体力 | **共用一条体力**（同伤共痛） | 同左（自律 / 设置 / 群体型例外，见 [04-astrals.md](04-astrals.md) 第 2 节） |
| 受伤倍率 | **×1.5**，本体是弱点 | ×1.0 |
| 移动 | 本体移动力（【建议】默认 3 格） | 伴星移动力（由"速"决定，C=3、B=4、A=5、S=6），并且**必须留在星绳范围内** |
| 行动 | 用道具、防御、鼓舞、收回 / 显现伴星 | 普攻和所有伴星技能 |
| 倒下 | 体力归零即倒下，伴星同时熄灭 | — |

伴星的三种状态：
- **显现**：默认状态，在战场上占一格，可以挡路、可以被攻击。
- **收回**：伴星回到本体体内。本体受伤倍率降到 ×0.7（伴星在体内护身），心力回复翻倍，但不能用伴星技能。下回合开始时可以免费再显现在本体相邻格。
- **熄灭**：本体倒下，或被摘星 / 封印。

**星绳**：本体移动后，如果伴星超出了星绳长度，伴星会被拉回到范围内最近的空格。伴星离本体越远，造成的伤害越低（第 6 节）。

## 4 时间轴【建议】

用"行动时间轴"决定谁先动，而不是简单的"我方回合 / 敌方回合"。

- 战场顶部是一条时间轴，显示接下来约 10 次行动的顺序（头像排成一排）。
- 每个角色行动后，按 `行动间隔 = 100 × 速度系数 × 动作权重` 排到时间轴后面。
  - 速度系数（按伴星"速"评级）：E 1.4 · D 1.25 · C 1.1 · B 1.0 · A 0.9 · S 0.8
  - 动作权重：轻动作（移动后待机、收回）0.7 · 普通 1.0 · 重技能 1.3
- 平手时，我方优先，然后按队伍顺序。
- 罗兹的「沙漏」专门操作这条轴：拖慢敌人、让队友插队。选择指令时，时间轴上要实时预览这个动作做完后自己会排到哪里。

## 5 一个角色的回合

1. **移动本体**（可选，最多本体移动力格；沙地、草丛等地形消耗更多）。
2. **移动伴星**（可选，在星绳范围内最多伴星移动力格）。
3. **一个主行动**：伴星技能 / 普攻 / 本体行动（道具、防御、鼓舞、收回）/ 待机。
4. 主行动确定之前，移动都可以撤销。

提示【建议】：先移动再行动是默认顺序；也可以设计"行动后还能移动"的特殊技能（比如沙漏）。

## 6 数值【建议】

所有数值确定、取整。

- **体力** = 本体基础（随等级成长）+ 韧加成（韧数值 × 0.5）
- **心力**：上限约 10–20，每回合自动 +2，收回状态 +4。技能消耗 1–6。
- **伤害** = 技能威力 × 力系数 × 星距系数 × 目标系数 × 破绽系数 × (1 − 韧减免)
  - 力系数 = 0.6 + 力数值 / 100
  - 星距系数：设伴星与本体距离为 d、星绳长为 R、半程 h = ⌈R/2⌉。d ≤ h 时为 1.0；d > h 时为 1.0 − 0.4 × (d − h) / (R − h)，满星绳处为 0.6。近身型的 R 很小，基本不受影响。
  - 目标系数：打本体 ×1.5；打收回状态的本体 ×0.7
  - 破绽系数：命中已被看破的破绽时 ×1.5 或按 Boss 的破绽设计
  - 韧减免 = 韧数值 / 250（S 级约 38%）
- **碰撞**：被击退撞到墙、柱子或其他单位时，双方各受固定碰撞伤害（【建议】10 点 × 击退距离），撞上的单位不移动。
- **治疗**：固定值 + 巧加成。

数值表全部放在数据文件里，便于调平衡。写一个模拟脚本，批量跑"标准队伍 vs 各章敌人"，检查回合数和伤害曲线是否合理。

## 7 战场地形【建议】

| 地形 | 效果 |
|---|---|
| 平地 | 无 |
| 沙地 | 本体移动消耗 2；伴星不受影响 |
| 草丛 | 站在里面的本体不会被远程技能选中 |
| 浅水 | 灼烧无效；冰冻持续 +1 回合 |
| 深水 / 海 | 不能站；被击退进去 = 落水：受伤，下回合不能移动（普通敌人直接出局） |
| 墙、石柱 | 阻挡移动和直线技能；碰撞来源 |
| 木箱、木桶 | 可以被推、被打碎；碎了可能掉道具 |
| 火盆、灯台 | 可以被晨星点燃：照亮周围格子（驱散雾、暗域）；被点燃的火盆可以被推倒造成灼烧 |
| 荆棘 | 进入时受伤；可以被晨星烧掉 |
| 冰面 | 在上面移动或被击退会一直滑到撞上东西为止 |
| 雾 | 格子里的单位看不见、意图不显示；被光照亮后消散 |
| 暗域（黑潮 / 永夜） | 里面的单位不能用技能 |
| 高台 | 站在上面的远程技能射程 +1 |

## 8 状态【建议】

不超过 12 种，图标 8×8，在单位头顶排一行。

| 状态 | 效果 |
|---|---|
| 灯印（1–3 层） | 晨星留下的标记，被「照破」引爆。**不会被倒带、复制、驱散清除** |
| 迟缓 | 时间轴上延后 |
| 冻结 | 跳过下一次行动；被攻击时解冻，受到额外伤害 |
| 锚定 | 不能移动；伴星星绳减半 |
| 灼烧 | 每次行动开始时受伤 |
| 暗盲 | 只能普攻 |
| 眩晕 | 跳过下一次行动 |
| 护盾 | 吸收一定伤害 |
| 鼓舞 | 造成伤害提升 |
| 坚守 | 受到伤害降低 |
| 破绽 | 法则被看破后标在 Boss 身上，提示可以利用 |
| 收回 | 伴星在体内护身（见第 3 节） |

## 9 意图【定】

**每个敌人下一次行动要做什么，提前公开显示。**

- 敌人头顶显示意图图标（攻击 / 技能 / 移动 / 强化 / 特殊）和预计伤害数字。
- 被瞄准的格子用红色网点（4×4 Bayer 抖动，不用半透明）标出。
- 意图分两种，图标不同：
  - **定点**：锁定格子。目标离开那些格子就能躲开。
  - **锁定**：锁定单位，跟着目标走，只能挡、减伤或在它行动前打断。
- 默认只显示每个敌人"下一次行动"的意图；薇奥拉的「预演」可以显示更多回合。
- 意图在敌人上一次行动结束时就决定好，之后不会因为玩家的移动而偷偷改变（除非被眩晕、击退出射程等，这时意图明确显示"中断"）。
- 鼠标悬停 / 光标移到敌人身上时，显示它的意图详情。

## 10 法则与看破【定】

这是本作的招牌系统。

- 每个 Boss（以及少数精英）的伴星有 1–3 条**法则**，开战时显示为"法则：？？？"卡片。
- 每条法则有**看破度**（【建议】3 格）。看破来源：
  - 在玩家视野内**亲眼看到法则生效**（+1）
  - 薇奥拉「观测」（+1；高"巧"时 +2）
  - 被法则影响的角色"巧"达到 B 以上（+1）
  - 特定的行动会直接触发看破（每个 Boss 自己设计，比如"站上天平托盘"）
- 看破度到 1 格时给一句模糊提示（"它好像只在……的时候才……"），满格时：
  1. 战斗暂停，角色们用 3–5 句话说出推理（侦探解谜的节奏）。
  2. 法则卡翻开，显示规则原文。
  3. 获得**破绽**：一个具体的对策或加成（例："天平两端人数相等时，戈德受到伤害 ×2"）。
  4. 全队觉悟 +15。
- **不看破也能赢**，只是更难更慢。不能做成"不看破就绝对打不过"的硬锁，防止玩家卡死。
- 法则用代码模块实现，挂在战斗事件上（回合开始、伤害结算、移动、行动结束等），见 [tech/architecture.md](../tech/architecture.md)。

## 11 觉悟、连打、双星技与演出【建议】

**觉悟**：全队共享的 0–100 槽。队友受伤、看破法则、击倒敌人、打中敌方本体都会增加。

**连打**：近身型和群体型的招牌技能。多段攻击，每段都有拟声大字（晨星："燃！燃！燃！"）。
- 可选的**节拍按键**：屏幕上一个圈收缩，按准了每次多打一段（最多 +5）。设置里可以关掉；关掉时按固定的中等结果结算（+2）。
- 最后一击附带击退。

**星爆**（觉悟 100）：每个角色的终极技。演出：画面定格 → 对角线分屏露出本体特写 → 伴星大招 → 拟声大字铺满屏幕。可跳过。

**双星技**（觉悟 100，两人羁绊达到要求且都在场）：两颗伴星的合体技。消耗当前角色的回合，搭档在时间轴上延后。组合见 [03-characters.md](03-characters.md) 第 4 节。

**防御按键**（可选）：敌人攻击命中瞬间按键，伤害 −20%。设置里可关。

**演出规范**：
- **伴星名片**：一颗伴星第一次登场（觉醒、Boss 登场、伙伴入队）时，画面定格，斜切分屏，本体立绘 + 伴星剪影 + 名字大字 + 六维星图画出来。1.5–2.5 秒，可跳过。这是本作的招牌画面，要做得很帅。
- **压迫感**：Boss 气势全开时，角色周围浮起原创的"星鸣"符号和"轰——"这样的大字，慢慢漂浮抖动。
- **打击感**：命中停顿 2–4 帧，屏幕震动 1–2 像素，受击单位用调色板换色闪白（不用半透明）。
- **速度**：设置里有动画速度 1× / 2× / 即时。

## 12 胜负与奖励【建议】

- **胜利**：所有敌方本体倒下（Boss 战可以有特殊条件，如"唤醒莫恩"）。
- **失败**：全员本体倒下 → "再来一次"（从本场开头重来）/ "回到灯柱"。不扣钱不扣经验，可以顺便降低难度。剧情要求的必败战不算失败。
- **撤退**：普通战随时可以撤退，敌人回到原位，主角获得几秒的无敌时间。Boss 战不能撤退。
- **奖励**：经验（本体等级）、星辉（伴星成长）、银铃（货币）、掉落物。
- **评价**：按回合数、是否无人倒下、看破了几条法则给 S/A/B/C，S 级额外给星辉。鼓励玩家打得聪明，而不是刷得多。

**最终战：维斯珀**（三阶段 + 剧情阶段，不会出现无法挽回的失败）
1. **「昏星」**：每 3 回合发动"摘星"，锁定一个队友（锁定意图提前一回合显示）。被摘中的伴星这一阶段被封印。对策：躲到 5 格外、城塞挡在中间（塔会被摘走，下阶段恢复）、晨星「灯罩」格挡。隐藏法则：昏星和晨星是双生之星，**灯印会降低他的防御**。
2. **「蚀」**：轮流使用前面各章 Boss 的能力（星税、冰棺、倒带……），每 2 回合换一种。以前学过的破绽在这里全部有效，是一场期末考试。
3. **「永夜」**：战场全黑，意图不显示，只有灯印和点亮的灯台周围能看见。他用 3 回合蓄力摘取晨星，全队要保护芬恩。
4. **「拂晓」**（剧情阶段）：蓄力结束时（不管玩家打得怎样）触发晨星进阶 IV。之后几回合是爽快的反击：旅途中遇到的携星者 NPC 每回合轮流出现援护（一句台词 + 一招），直到击败维斯珀。

## 14 敌人 AI【建议】

- 确定性的打分 AI：对每个可选行动打分（伤害、能否击倒、打本体加分、保护自己本体、法则脚本加分），选最高分；平分时按固定顺序选。不能用随机数。
- 敌人也会保护本体：本体会躲在伴星后面、躲进草丛。
- Boss 的每个阶段可以有脚本化的行动序列，与打分 AI 混用。
- AI 必须"可读"：玩家应该能大致猜到敌人为什么这么做。

## 15 难度与无障碍【建议】

| 难度 | 说明 |
|---|---|
| 故事 | 敌人伤害 ×0.6，意图多显示 1 回合，所有按键时机自动判定为良好 |
| 标准 | 默认 |
| 挑战 | 敌人体力 +30%，Boss 多一条法则或更快的节奏，失败后不能降低难度重试 |

随时可以在设置里切换（挑战除外）。其他：动画速度、关闭屏幕震动、关闭闪白、按键时机开关。

## 17 实现要点【定】

- 战斗逻辑写成**纯逻辑、确定性的状态机**：输入"当前状态 + 指令"，输出"新状态 + 事件列表"。不碰渲染、不碰时间、不碰随机。
- 渲染层只负责把事件列表播成动画。这样可以：写单元测试、做战斗回放、跑平衡模拟、让自动通关机器人打完所有战斗。
- 战斗定义（战场、单位、AI 档案、法则模块）全部放在数据文件里。每条法则一个代码模块，配一组单元测试。

## M1 逻辑实现补充（2026-10-25）【建议】

- 防御暂以20点护盾表达；月桂护盾为18+floor(巧/10)，与现有护盾取高，不累计叠加。正式平衡会在序章完整试玩中调整。
- 地图移动先累计消耗，撤销恢复本回合移动起点；免费显现只在未移动时一次，撤销移动保留首次显现位置，不重置显现资格。
- 射线采用覆盖沿途格的整数算法，紧贴墙角的斜线也阻挡；当前近身/远隔单位本身不挡射线，设置型拦截留到对应章节。
- 碰撞按共享体力所属角色去重；伴星撞到自己的本体只结算一次固定伤害，撞另一位角色则两位各结算一次。初伤致死后不再击退。
- 序章剧情目标单独计数指定敌人的真实主行动；芬恩倒下优先判败。剧情生命底线只允许配置给该目标敌人，不能用于普通战。穿过护盾但被剧情底线阻止扣血仍算有效命中，避免目标死局；全盾吸收或零伤害不计。
- `rush`目前是供击退校验使用的单次逻辑技能；M2的正式多段连打/节拍/喊声尚未实现，不能把它当成完成版连打。

## 固定意图的路径落地（2026-10-25）【建议】

公布移动计划时同时固定逐格路径；占住原路径中的任一格即可阻断该计划，不能在行动时偷偷寻找替代路线。即使原路仍可走且出现捷径，也继续原路。中断不执行任何移动前缀，攻击型意图仍支付原技能心力和行动间隔；预报显示零扣血与中断原因。玩家普通选格移动仍可即时寻路。本项是对既定“意图不暗改”的落实，未修改【定】。
