# 09 · 界面与交互

## 1 画面规格【建议】

| 项 | 规定 |
|---|---|
| 逻辑分辨率 | **480×270**（16:9）。整数倍放大、最近邻采样，窗口多余部分黑边。1080p 下 4 倍 |
| 格子 | 16×16 |
| 字体 | Fusion Pixel 12px（OFL，支持简体中文），可从 ele-pushbox-arts 的 `third_party/fonts/` 连许可证一起拷贝。最近邻渲染，关闭抗锯齿。小字可用 10px 版 |
| 文字 | 所有界面文字来自多语言表，不画文字贴图（伴星名片的大标题可以用代码画的放大字形） |
| 面板 | 九宫格边框，不透明底色，不用渐变 |

## 2 视觉风格

界面和游戏画面是同一种像素风：深色描边、两三阶明暗、温暖的配色。【建议】主题是"星图与灯"：
- 面板底色是深靛蓝夜空色，边框是暖金色细线，四角有小星星。
- 选中项前面是一个小灯笼形光标，会轻轻摇晃。
- 重要数字（伤害、评级）用描边的大号像素数字。

## 3 画面清单【建议】

| 分组 | 画面 |
|---|---|
| 开始 | 启动画面 · 标题（夜空 + 灯谷镇剪影 + 流星）· 存档选择 · 设置 |
| 地图 | 地图 HUD（左上区域名淡入淡出、右上任务提示、交互提示图标）· 对话框 · 选项框 · 表情气泡 · 获得物品提示 · 世界地图 |
| 菜单 | 主菜单 · 队伍（本体资料 + 伴星星图）· 伴星详情（星图、技能、类型、档案）· 星轨 · 星阶 · 道具 · 星饰 · 任务日志 · 星图鉴 · 存档 / 读档 |
| 战斗 | 战斗 HUD · 时间轴 · 指令菜单 · 技能列表 · 目标选择（显示范围和预计伤害）· 意图显示 · 法则卡 · 看破推理演出 · 连打节拍 · 伴星名片 · 星爆 / 双星技演出 · 胜利结算（经验、星辉、感悟、评价）· 失败 |
| 成长 | 灯柱营火菜单 · 修行选择 · 五个修行小游戏 · 修行结算（星图动画）· 营火对话选择 · 心之试炼入口 |
| 城镇 | 商店 · 委托板 · 星屑兑换 |
| 剧情 | 静帧插画 · 章节标题卡 · 结局群像 · 制作人员名单 |

开发者可以学 ele-pushbox-arts 的做法：先在工作台里把每个画面画成静态参考图（中文和英文各一版，检查文字放不放得下），确认版式后再接进游戏。

## 4 对话框【建议】

- 位于屏幕下方，宽约 440、高约 64 像素，左侧放 48×48 头像（带表情），名字牌贴在左上角。
- 每行约 30 个汉字，最多 3 行，文字逐字出现，可以按键立即显示全部。
- 头像表情至少：普通、笑、怒、惊、悲、思考。
- 说话人在画面里时，头顶出现一个小三角指示。

## 5 战斗界面【建议】

```
┌──────────────────────────────────────────────┐
│ [时间轴：头像 头像 头像 头像 头像 …]           │  ← 顶部
│                                              │
│            战场（地图原地，战场外压暗）          │
│        敌人头顶：意图图标 + 伤害数字             │
│                                              │
│ [法则卡 ？？？]                    [觉悟槽]   │
│ ┌────────┐ ┌───────────────────────────────┐ │
│ │当前角色 │ │ 指令：技能 / 普攻 / 本体 / 收回 │ │  ← 底部
│ │体力 心力│ │ 技能说明、消耗、预计效果         │ │
│ └────────┘ └───────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

- 选技能后，战场上显示范围（蓝色网点）和受影响的单位，单位头上显示预计伤害、击退后的位置。
- 时间轴实时预览这个动作做完后自己排到哪里。
- 光标移到任何单位上，显示它的状态、意图、法则看破度。
- 所有半透明效果用网点抖动代替。

## 6 操作【建议】

| 动作 | 键盘 | 手柄 |
|---|---|---|
| 移动 / 光标 | 方向键 / WASD | 十字键 / 左摇杆 |
| 确认 / 交互 | Z / 空格 / 回车 | A |
| 取消 / 返回 | X / Esc | B |
| 菜单 | C / Tab | Start |
| 伴星（场外技能 / 先手） | V | X |
| 跑步 | 按住 Shift | 按住 B |
| 切换领队 | Q / E | LB / RB |
| 战斗：查看敌人意图详情 | A | Y |
| 对话快进 | 按住 X | 按住 B |

- 鼠标也可以操作所有菜单和战斗选择（点击、悬停查看）。
- 按键可以在设置里重新绑定。界面上的按键图标随最后使用的输入设备切换。

## 7 设置与无障碍【建议】

音乐音量、音效音量、文字速度、自动播放、战斗动画速度（1× / 2× / 即时）、难度、按键时机开关、屏幕震动开关、闪白开关、画面放大倍数、全屏、按键绑定、语言。

## 8 反馈规范

- 每次按键都要有回应（声音或画面），不能"按了没反应"。
- 不能操作时给一个轻微的"拒绝"反馈（短音 + 小幅抖动），不惩罚。
- 读档、切换地图、进入战斗都不能超过 1 秒的黑屏。
