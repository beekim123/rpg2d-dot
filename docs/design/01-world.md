# 01 · 世界观

## 1 一句话设定

阿斯特拉大陆的夜空曾经有一颗最亮的星，叫**天心**。三百一十二年前它碎裂坠落，碎片化成看不见的**星尘**，渗进风、水、土地和人心。从那以后，任何人都可能在意志最强烈的一刻**觉醒**：体内的星尘凝聚成一个独立的灵魂化身，叫**伴星**。拥有伴星的人叫**携星者**，没有的人叫**无星者**。

## 2 伴星七法则【定】

这是世界的"物理规则"。剧情、战斗和谜题都必须遵守它们；剧情里的反转也只能来自对法则的新发现，不能凭空推翻法则。

| # | 法则 | 世界里的含义 | 落到玩法上 |
|---|---|---|---|
| 1 | **一人一星** | 伴星是本人灵魂的形状，不能选择，也不能转让 | 每个角色只有一颗伴星，能力和性格挂钩 |
| 2 | **唯星可见** | 只有携星者看得见、碰得到伴星；无星者只看得到它造成的结果 | 剧情里的"怪事件"、无星者的误解和恐惧；画面上玩家始终能看见伴星 |
| 3 | **同伤共痛** | 伴星受的伤会回到本体身上 | 本体和伴星共用体力；自律型伴星例外（见 [04-astrals.md](04-astrals.md)） |
| 4 | **星距** | 伴星离本体越远越弱，超出射程就会消散 | 战斗中伴星被一条"星绳"拴在本体周围；离得越远伤害越低 |
| 5 | **星随心长** | 伴星随本体的意志与锻炼成长；心境发生重大转变时会**进阶** | 修行提升六维；剧情节点触发星阶进阶 |
| 6 | **本体倒下，伴星熄灭** | 本体失去意识，伴星就会消失 | 本体体力归零即该角色倒下；攻击敌方本体是高风险高回报的选择 |
| 7 | **摘星**（禁忌） | 伴星可以被强行从本体身上剥离、封存。被摘星的人会陷入"失星沉睡"，身体慢慢衰弱 | 主线的核心谜团。前期只有传闻，中期揭开 |

补充说明：
- **觉醒条件**：在生死关头、强烈的决意、悲伤或爱意的"临界"时刻才可能觉醒。大多数人一辈子都不会觉醒。大约每两百人里有一个携星者。
- **伴星的名字**：觉醒的那一刻，名字会自己浮现在心里。伴星名一律是"中文名 + 英文名"，例如「晨星 MORNING STAR」。【定】
- **伴星不一定能打**：有的伴星只会让面团发酵，有的只会帮人找钥匙。这是世界的幽默来源，也是支线故事的素材。

## 3 历史年表【建议】

纪年用"星落历"，星落之夜为元年。

| 年份 | 事件 |
|---|---|
| 星落前 | 人们信仰天心，叫它"众星之母"。大陆由十几个城邦松散结盟 |
| 元年 | **星落之夜**：天心碎裂，坠落在大陆正中央，砸出巨坑「星坠之渊」。之后连续三年"星雨"不停 |
| 约 50 年 | 第一批觉醒者出现，人们称他们为"被星选中的人"。崇拜和恐惧同时出现 |
| 50–120 年 | **星乱时代**：携星者割据称王，城邦战争不断，无星者备受欺压 |
| 120 年 | 七位携星者与各城邦缔约，建立**星见院**，定下《携星法典》：携星者必须登记，禁止用伴星伤害无星者。星乱结束。**阿斯特拉同盟**成立，首都天枢城 |
| 120–280 年 | 和平年代。星见院成为凌驾于城邦之上的权威 |
| 约 282 年 | 北境小镇"霜溪"发生惨案：一个刚觉醒的少女伴星失控，全镇烧毁。唯一的幸存者是她的弟弟维斯珀（后来的大司星，见 [03-characters.md](03-characters.md)） |
| 300 年 | 维斯珀就任**大司星**（星见院之首），推行"星籍严管"，各地设立星卫所 |
| 309 年起 | 各地陆续出现**失星事件**：携星者昏睡不醒，伴星不知去向。坊间流传一个戴月牙黑面具的组织"蚀星会" |
| **312 年** | **游戏开始**。灯谷镇的星落祭之夜 |

## 4 社会

- **携星者**：必须在星见院登记，领取"星籍牌"。可以进星见院当**观星官**（调查员）或**星卫**（执法者），也有很多人隐瞒觉醒，过普通日子。未登记的携星者被叫作"**野星**"，会被追捕。
- **无星者**：绝大多数人。对携星者的态度从崇拜到恐惧都有。有的地区（雾语林）把携星者视为"被星附身的怪物"。
- **星见院**：总部在天枢城的星见塔。表面上是保护所有人的秩序守护者，实际上被大司星掌控，暗中与蚀星会是同一张网（主线揭示）。
- **蚀星会**：秘密组织，成员戴月牙黑面具。专门"摘星"，收集伴星封进**星匣**。其中的普通士兵装着从被摘之星上削下的碎片，叫**赝星**：灰色、没有面孔、只会简单攻击。
- **星兽**：吸收了星尘的野生动物和物件。外形像带着星斑的动物、会动的石像、发光的蘑菇等，是野外的普通敌人。
- **宗教**：民间仍有"拜星"习俗。每年星落之夜举办**星落祭**：放灯、点灯、吃星星形状的甜饼。

## 5 地理【建议】

大陆大致呈一枚倾斜的星形，正中是星坠之渊。主线沿逆时针绕大陆一圈，最后走进正中央。

```
              霜脊要塞（北·雪山）
                  │
  雾语林 ────── 天枢城（中央高原）────── 白鸥港（东·海岸）
（西·雾林）       │                           │
                星坠之渊（正中·巨坑）          │
                  │                           │
  灯谷镇（西南·草原）── 赤砂城（南·沙漠）───────┘
```

| 区域 | 地貌与氛围 | 城镇特色 | 主色调 |
|---|---|---|---|
| **灯谷镇** Lantern Vale | 起伏草原、麦田、风车、溪流、成排的灯柱 | 点灯人公会，每家门口一盏灯 | 嫩绿、麦黄、暖橙灯光 |
| **赤砂城** Redsand | 沙漠绿洲、砂岩城墙、圆顶、集市帐篷 | 四塔城堡、热闹的大集市、赌坊 | 沙黄、赭红、青绿布篷 |
| **雾语林** Whisperwood | 终年起雾的巨木森林、发光蘑菇、苔藓石碑 | 树屋村落，排斥携星者 | 深绿、雾灰、荧光青 |
| **白鸥港** Gullhaven | 海岸悬崖、灯塔、栈桥、船坞、礁石 | 渔市、船厂、水手酒馆 | 海蓝、白帆、木褐 |
| **霜脊要塞** Frostspine | 雪山、冰川、黑岩、风雪 | 星见院的"星牢"要塞 | 冰白、冷蓝、铁灰 |
| **天枢城** Zenith | 高原上的大城，钟楼、齿轮、星见塔、运河 | 首都、钟表街、学院、地下水道 | 白石、金、靛蓝 |
| **星坠之渊** Starfall Abyss | 巨坑、浮石、星晶、倒流的光、残缺的星空 | 无（终局迷宫） | 深紫、星金、黑 |
