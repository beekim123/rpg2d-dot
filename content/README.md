# 游戏内容源

这里保存与引擎无关的可编辑数据，引用使用稳定 ID。

| 子目录 | 内容 |
|---|---|
| `data/` | 角色、伴星、技能、战斗配置等数值表 |
| `maps/` | 地形字符串行、实体、碰撞、出口与阶段显隐 |
| `story/` | 带稳定文字 ID 的剧情指令 |
| `i18n/` | 所有玩家可见文字；当前以简体中文为主 |

修改后运行 `npm run content:check`，并跑受影响的逻辑/通关路线。新数据不能仅靠 JSON 语法正确就算接入完成；运行时登记、引用、可达性和剧情无死局要分别验证。

`maps/prologue/` 的五图和剧情草稿仍是迁移候选。Godot G0 目前只同步灯谷测试地图与中文表；新增条目由资源包同步配置明确登记，`godot/data/` 只保存生成副本，不手工编辑。权威设计与验收状态见 [`docs/`](../docs/README.md)。

`registry.json` 登记进入Godot的地图逻辑ID、内容相对路径、语言表和启动地图。当前为旧验证地图与序章五图；地图内部ID必须与登记键一致。不要通过在同步器里硬编码文件名添加地图。
