# 伴星 ASTRA（暂定名）

> 每个人心里，都有一颗会醒来的星。

2D 俯视角像素风回合制 RPG。三百年前天上最亮的星碎裂坠落，从此任何人都可能觉醒属于自己的"伴星"，一个由灵魂化成的战斗化身。你是一个刚觉醒的点灯人学徒，为了夺回姐姐被偷走的伴星踏上旅途。

- 本体 + 伴星的格子回合制战斗：保护本体、控制星距、看破敌人伴星的隐藏法则
- 修行小游戏、星轨技能树、星阶进阶：看着自己的伴星一点点变强
- 序章 + 7 章 + 终章的完整故事
- 美术全部由代码绘制，音乐音效全部由代码合成
